🧩 Power Platform plugins

Agent plugins for Microsoft Power Platform, Dataverse and Dynamics 365 delivery. Add one marketplace to VS Code (GitHub Copilot), Copilot CLI or Claude Code, then install the plugins you need.

🧪 dataverse-poc

Dataverse POC · multi-agent · Italian

An orchestrator plans the POC and delegates to sub-agents. They build the HTML/YAML prototype, data model, demo data, forms, views, generative pages, PCF controls, web resources and code apps, then test and deploy. Deterministic scripts do the mechanical work.

📖 power-platform-llm-wiki

Project knowledge base · D365 CE / Power Platform / F&O

A code-first wiki that stays aligned with the code. It covers repositories, Dataverse and F&O metadata, work items, meetings and FDD/TDD, and publishes to Azure DevOps Wiki or GitHub Wiki.

⌨️ Copilot CLI

copilot plugin marketplace add raythekool/power-platform-plugins
copilot plugin install <plugin>@power-platform-plugins

🟠 Claude Code

claude plugin marketplace add raythekool/power-platform-plugins
claude plugin install <plugin>@power-platform-plugins

🟦 VS Code

Add raythekool/power-platform-plugins to chat.plugins.marketplaces, then search @agentPlugins in the Extensions view.
